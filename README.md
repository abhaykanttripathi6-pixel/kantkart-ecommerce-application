# KantKart

A modern, responsive e-commerce web application built with **React**, **Vite**, and **Tailwind CSS**. The project features product browsing, filtering, wishlist, cart management, authentication, checkout functionality, and responsive design.

## Features

- Responsive navigation bar
- Product search and filtering
- Category-based product browsing
- Sorting and pagination
- Product details page
- Wishlist functionality
- Add to cart and quantity management
- Cart item selection for checkout
- Buy Now functionality
- User authentication with Clerk
- Checkout and order management
- Pincode validation
- Responsive design for mobile, tablet, and desktop
- Lazy loading for improved performance
- Reusable React components
- Toast notifications
- Smooth UI animations

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Clerk
- React Icons
- Swiper
- Framer Motion
- React Toastify
